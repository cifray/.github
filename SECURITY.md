# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público. Escribí a **seguridad@cifray.app** con la descripción, los pasos para reproducir y el impacto estimado. Respondemos dentro de las 72 h hábiles.

## Plazos de remediación

| Severidad                                  | Plazo en producción            |
| ------------------------------------------ | ------------------------------ |
| Crítica (CVSS ≥ 9 o explotada activamente) | 48 h                           |
| Alta                                       | 7 días                         |
| Media                                      | 30 días                        |
| Baja                                       | Próximo ciclo de actualización |
