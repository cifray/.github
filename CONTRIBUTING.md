# Cómo contribuir

1. Creá una rama desde `main`: `feat/…`, `fix/…`, `docs/…` o `chore/…`.
2. Commits en formato [Conventional Commits](https://www.conventionalcommits.org/es/).
3. Abrí un Pull Request contra `main` con la plantilla completa.

Las reglas del proyecto están en el `CONTRIBUTING.md` de cada repo.
